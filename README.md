Desktop Replacement Documentation (INC0012871)
Overview

This project documents the resolution of a critical desktop failure for a Customer Support agent who was unable to take calls due to a completely non-functional workstation. A replacement desktop was built, configured, verified, and shipped using the organization's imaging and deployment process.

Key Objectives
Diagnose the workstation failure.
Deploy a replacement desktop using the approved imaging procedure.
Verify domain functionality and system readiness.
Ship the replacement device with a return label for faulty hardware recovery.
Document the process and resolution for future reference.
Technologies & Skills Demonstrated
Incident Management
Operating System Deployment (OSD)
PXE Network Boot
Desktop Imaging
Active Directory Domain Sign-in Verification
Asset Management
IT Documentation
Customer Communication
Hardware Replacement Logistics
Outcome

Successfully resolved ticket INC0012871 by deploying and shipping replacement desktop SD1341 via Rush Priority. The device was verified through domain sign-in, delivered with a return label, and the incident was closed with full documentation.
